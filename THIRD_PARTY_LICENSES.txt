THIRD-PARTY LICENCES
====================

fMCG redistributes third-party libraries in binary form. This file contains
the licence notices required by those licences. fMCG itself is licensed under
the GNU GPL-3.0 (see LICENSE).

Contents
--------
  fMCG.exe links (Windows: all statically -- the exe needs no DLLs):
    Dear ImGui (MIT), GLFW (zlib licence), XXHash64 by Stephan Brumme (MIT),
    HarfBuzz (Old MIT), stb_truetype (public domain/MIT), x264 (GPL-2.0+),
    libarchive (BSD-2 + notes below), zlib (zlib licence), bzip2 (BSD-style),
    liblzma / XZ Utils (0BSD), Zstandard (BSD-3), LZ4 (BSD-2),
    MinGW-w64 GCC runtime (GPL + linking exception)
  On Linux the system libarchive / HarfBuzz / x264 shared libraries are used.
