THIRD-PARTY LICENCES
====================

fMCG redistributes third-party libraries in binary form. This file contains
the licence notices required by those licences. fMCG itself is licensed under

Contents
--------
  fMCG_gui.exe   links: Dear ImGui (MIT), GLFW (zlib licence), MinGW-w64 GCC
                        runtime (GPL + linking exception)
  libarchive.dll embeds: libarchive (BSD-2-style), zlib (zlib licence),
                         bzip2 (BSD-style), liblzma / XZ Utils (0BSD),
                         Zstandard (BSD-3), LZ4 (BSD-2), libxml2 (MIT),
                         libiconv (LGPL-2.1)
  FFmpeg         NOT included in this package; install separately. It is
                 GPL/LGPL licensed -- see https://ffmpeg.org/legal.html
